# Poppa

En lugn och stillsam ballong-app för barn (PWA). Ballonger stiger sakta uppåt –
tryck på en så poppar den, ljudlöst och mjukt, och snart kommer en ny.

Öppna **https://isak-wallo.github.io/Poppa/** i Chrome på plattan och välj
"Lägg till på hemskärm" för att installera den (fungerar sedan offline).

Poppa kan också byggas som en riktig Android-app (APK) med Capacitor:
`python verktyg/bygg_apk.py` (kräver Node, Java 21 och Android SDK). Appen
ligger då i helskärm, är låst i landskap, fäster sig själv och bakåtknappen
gör ingenting.

Syskon-app till [Kludd](https://github.com/isak-wallo/Kludd).
